# カスタム管理 - APEX カスタムマッチ管理アプリ

APEX Legends のカスタムマッチ（チームデスマッチ／バトルロイアル）を管理するための Web アプリです。

## 機能

### 共通

- **カスタム作成・管理** — カスタム名とモード（バトルロイアル：トリオ／デュオ、チームデスマッチ）を選んで作成・編集・削除
- **ダークモード** — システム設定に連動、手動切り替えも可能

### チームデスマッチ (TDM)

- **プレイヤー登録** — プレイヤーをランク付きで登録して管理
- **チーム分け** — レベル順（スネークドラフト）またはランダムでチームを自動振り分け、分け方アニメーション付き
- **チーム名編集** — チームヘッダーをクリックしてインラインで名前を変更
- **マップルーレット** — TDM マップをランダムで決定（使用しないマップの除外可能）
- **レジェンド縛り** — プレイヤーにレジェンドをランダム割り当て（ロール除外・チーム別同構成モード対応）
- **武器縛り** — スロット 1〜5 のトグル選択・ランダム決定（選択数指定可能）
- **テキスト特別ルール** — 自由にルールを追加

### バトルロイアル（トリオ／デュオ）

- **チーム単位の参加登録** — 参加チーム数を選ぶと、モードに応じた人数分（トリオ3人／デュオ2人）のランク枠を自動生成
- **試合結果の記録** — 試合ごとにキル数・順位を入力、試合数は自由に追加可能。試合タブで切り替えながら入力
- **同一試合内の順位重複防止** — 他チームが選択済みの順位はプルダウンで選択不可に
- **ランキング表示** — 「ランキング」タブで全チームを累計スコア順に表示（合計キル・優勝回数・最高順位、参加メンバーも表示）
- **カスタム設定** — ランク制限ポイント表・キルポイント上限（試合ごとON/OFF）・順位ボーナス・ハンデ（上限不足分加算・女性ディスカウント）をすべて設定ダイアログから編集可能
- **共有テキストコピー** — チームごとの結果・累計スコアをテキストとしてコピー
- **レスポンシブレイアウト** — PC画面では複数チームを横並び（最大5列）で表示

## 技術スタック

- [Next.js 16](https://nextjs.org/) (App Router)
- [Tailwind CSS v4](https://tailwindcss.com/)
- TypeScript
- localStorage によるデータ永続化

## 開発

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) で確認できます。

## デプロイ

Vercel へのデプロイを推奨します。

```bash
npm run build
```
